# &#x20;PintAmano

Página web dedicada al arte de pintar camisetas a mano, inspirada en la creatividad, los detalles y la belleza de la tierra de Barichara.

## Tecnologías

- HTML5
- CSS3

## &#x20;Objetivo

Presentar diseños pintados a mano que transforman camisetas en piezas únicas, resaltando el arte y la identidad cultural.

---

Proyecto realizado como práctica de desarrollo web.
